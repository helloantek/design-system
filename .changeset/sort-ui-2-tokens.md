Add the Sort UI 2.0 tokens next to the 1.3 ones (first stage of the migration, see docs/migration-sort-ui-2.md): colours for Light and Dark (`--ds-background`, `--ds-muted-foreground`, `--ds-palette-*`, `--ds-alpha-*`…), radius, spacing (`--ds-spacing-*`), typography (`--ds-text-*`, `--ds-font-*`), opacity, motion and effect styles (`--ds-shadow-*`, `--ds-controls-*`, `--ds-surface-*`). Nothing existing changes.
