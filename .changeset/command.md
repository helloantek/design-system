Command (Sort UI 2.0): `Command` (`label`, `search` / `defaultSearch` / `onSearchChange`, `shouldFilter`, `loop`, `width`, `plain`), `CommandInput`, `CommandList`, `CommandGroup` (`heading`), `CommandItem` (`icon`, `description`, `shortcut`, `checked`, `disabled`, `value`, `keywords`, `onSelect`), `CommandSeparator`, `CommandEmpty` and `CommandDialog`. The search field is a combobox: arrows move the selection, Enter runs it, typing filters items and hides empty groups, and the empty state shows when nothing matches.
