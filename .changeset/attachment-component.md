Add Attachment (Sort UI 2.0): a file added to a message or a composer, as a row (`file`, `file-sm`), a square card (`card`) or a picture (`image`), while it uploads, once it is done and when it fails, with a title, a size or address, an error, a type label, a file icon, a picture and ghost icon-button actions (shown on hover or focus on cards and pictures). `href` makes it a link; `AttachmentGroup` lines several up in a row or a column.
