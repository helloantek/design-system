Sidebar (Sort UI 2.0): `SidebarLayout` (`collapsed` / `defaultCollapsed` / `onCollapsedChange`), `Sidebar` (`variant` default / floating), `SidebarHeader`, `SidebarContent`, `SidebarFooter`, `SidebarGroup` (`label`, `labelSize`, `action`, `collapsible`), `SidebarMenuItem` (`icon`, `href`, `active`, `size` default / sm / lg, `description`, `badge`, `action`, `endIcon`, sub items as children), `SidebarTrigger`, `SidebarInset` and `useSidebar`. The trigger collapses the sidebar to a 48 px icon rail; sub menus and collapsible groups animate open; narrow screens start collapsed and lay the open sidebar over dimmed content.
