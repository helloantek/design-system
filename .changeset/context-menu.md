Context Menu (Sort UI 2.0): `ContextMenu` opens the Dropdown Menu parts at the pointer on a right-click, or with Shift+F10 / the Menu key, kept inside the viewport, with the menu keyboard of Dropdown Menu. `DropdownMenuRow` and `DropdownMenuIconItem` add a row of 32 px icon or emoji items (the "Chat message" demo's reactions).
