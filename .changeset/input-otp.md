Input OTP (Sort UI 2.0): `InputOTP` takes a one-time code of `length` characters (`value`, `defaultValue`, `onValueChange`, `onComplete`) in slots joined in 1–3 `groups` with a `separator`, or as `cells`; `pattern` keeps digits, letters and digits or a RegExp, and `invalid`, `disabled` and `fullWidth` follow Figma and its demos. One invisible `<input autocomplete="one-time-code">` takes typing, paste and code autofill, and it works inside a Field.
