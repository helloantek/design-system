Input now follows Sort UI 2.0 (Input, Input Group, Field, Kbd): 36 px (`lg`) and 32 px (`sm`) fields with a 10 px radius, 13 px text, a 2 px focus ring, a red stroke and ring when invalid, 50 % opacity when disabled, 14 px label and description, a Kbd-style shortcut and an Outline xs button for `action`. The API is unchanged: `shadow` adds Shadow/xs and `soft` is a borderless tinted field. Select keeps its Sort UI 1.3 label and caption until it moves to 2.0.
