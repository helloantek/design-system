Button Group (Sort UI 2.0): `ButtonGroup` (`orientation`) joins Buttons, a Dropdown Menu's button, an Input or a Select into one control with only the outer corners rounded and shared strokes dropped; a group of groups spaces them 8 px apart. `ButtonGroupText` adds a label segment (e.g. a URL prefix). Button's stroke can now be reshaped with `--btn-stroke-shape`.
