New ApprovalCard, the first of the Sort UI 2.0 patterns (Patterns/Approval Card): an agent asks before it acts. A header with the action and a risk badge, details (`ApprovalCardDetails`, `ApprovalCardSummary`, `ApprovalCardPreview`), "Always allow this action" or a countdown, and Deny (Esc) / Approve (Enter). While approving it is busy; once approved, denied or expired it folds to one status line with an optional Undo.
