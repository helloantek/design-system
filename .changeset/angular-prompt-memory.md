The patterns Prompt Library and Memory Panel for Angular, with the React components' markup and behaviour: `<section dsPromptLibrary>` (a searchable list of templates, fields for the gaps, the prompt assembling with its token count, Copy and Use prompt with ⌘↵) and `<section dsMemoryPanel>` (Use memory, categories, every memory with Edit in place, Pause and Forget with Undo, New memory; the list scrolls past `listMaxHeight`).
