Select: `multiple tags` shows the values as removable badges (Figma Variant=Tags): × with the mouse, Backspace/Delete removes the last one, removals are announced. Tags that do not fit wrap, or with `tagsOverflow="count"` stay on one row with a "+N" badge. Badge: `removeButton={false}` draws the Close Icon as a pointer target for badges inside another control.
