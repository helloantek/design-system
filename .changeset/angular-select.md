Select for Angular, with the React Select's markup and behaviour: `<ds-select>` with `options` as data (options, groups, separators, captions; an option's `caption`, `description`, `badge`, `disabled`, and `icon` / `media` as templates that get the option as context), `label`, `caption`, `error`, `placeholder`, `variant`, `size`, `indicator` (check, Checkbox or Radio), `multiple`, `tags` with `tagsOverflow`, `disabled`, `required`, `name` (hidden inputs) and `[(open)]`; `dsLeadingIcon` / `dsTrailingIcon` mark the field's icons. Keyboard (arrows, Home/End, PageUp/PageDown, Enter/Space, Escape, Tab, type-ahead) uses ds-core's list navigation and type-ahead, as React does. The value (`[(value)]`: a string or `null`, a list with `multiple`) works with Signal Forms, Reactive Forms and `ngModel`.
