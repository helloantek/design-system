# @helloantek/ds-angular

## 2.58.0

### Minor Changes

- badf009: The patterns Context Window, AI Answer, Cited Answer and Inline Diff for Angular, with the React components' markup and behaviour: `<section dsContextWindow>`, `<article dsAIAnswer>` (with `dsAIAnswerPoints`, `dsAIAnswerPoint`, `dsAIAnswerCitation`, `dsAIAnswerCaret`), `<article dsCitedAnswer>` and `<section dsInlineDiff>` (Y and N on the focused edit, Accept all, Reject all, Undo). The Context Window maths, `formatTokens` and `contextCells`, moved to ds-core (ds-react re-exports them as before).
- eff8c25: Bubble and AI Chat Composer for Angular, with the React components' markup and behaviour: `<div dsBubble>` and `<div dsBubbleGroup>` (variants, alignment, reactions on a corner, a long message with Show more) and `<div dsAIChatComposer>` (the prompt grows with its text and turns into a column when it wraps, Enter sends, /commands are tinted, Expand, dictating and transcribing; content marked `dsComposerLeading`, `dsComposerBadges`, `dsComposerModel`, `dsComposerHeader`), with `<mark dsAIChatComposerToken>`. Model Picker and Thinking Loader get their stories in the composer and in a chat.
- 15343dd: Popover, Switch and the pattern Message Actions for Angular, with the React components' markup and behaviour: `<div dsPopover>` (its trigger marked `dsPopoverTrigger`; a named non-modal dialog that takes focus, closes on Escape, a click outside or focus leaving, and on a `dsPopoverClose` button; `side`, `align`, `width`, `[(open)]`; `dsPopoverActions`), `<ds-switch>` (a native checkbox with `role="switch"`, with a label, caption or error; `[(checked)]`, Reactive Forms, ngModel and Signal Forms) and `<div dsMessageActions>` (Copy, Regenerate with versions, thumbs up and down with what was wrong in a Popover, Read aloud).
- 5b4194f: The pattern Model Picker for Angular, with the React component's markup and behaviour: `<ds-model-picker>` with each model's logo as an `<ng-template dsModelPickerIcon="value">`; pointing at a model (mouse or arrow keys) shows its speed, quality and cost, Enter or a click chooses it; extended thinking (`thinkable`, `[(thinking)]`) with its effort (`[(effort)]`); `[(value)]`, `[(open)]`, `align`.
- f35642f: Tooltip and Dialog for Angular, with the React components' markup and behaviour. `<ds-tooltip>` goes around its trigger (`content`, `side`, `shortcut`, `delay`, `[(open)]`, an icon marked `dsIcon`): it describes the trigger, shows on hover after the delay or at once on keyboard focus, and flips and shifts inside the window with ds-core's placement maths. `<ds-dialog>` is a native modal `<dialog>` (`title`, `titleAs`, `description`, `closeButton`, `closeLabel`, `bodyPadding`, `footerVariant`, `width`, `[(open)]`): `dsDialogTrigger` marks the element that opens it, `<ng-container dsDialogFooter>` holds the actions and `dsDialogClose` closes it from a button; Escape, the Close button or the backdrop close it and focus returns to the trigger.
- ab05473: Kbd, Spinner, Toggle, Toggle Group and Avatar for Angular, with the React components' markup and behaviour: `<kbd dsKbd>` and `<kbd dsKbdGroup>` (`variant`, `size`, a spoken `label` for symbols), `<span dsSpinner>` (`variant`, `size`, `label` or `decorative`), `<button dsToggle>` (`variant`, `size`, `[(pressed)]`, icon slots), `<div dsToggleGroup>` with `<button dsToggle value="…">` items (`type` single or multiple, `[(value)]`, `variant`, `size`, `spacing`, `orientation`, `disabled`; one Tab stop and the arrow keys), and `<span dsAvatar>` (`src`, `initials`, `name`, `size`, `shape`, `ring`, a fallback when the picture fails) in `<span dsAvatarGroup>` (`size`, `total` for "+N").
- e8e2938: The patterns Approval Card, Tool Call Card and Permission Request for Angular, with the React components' markup and behaviour: `<article dsApprovalCard>` (with `dsApprovalCardDetails`, `dsApprovalCardSummary`, `dsApprovalCardPreview`, `dsApprovalCardRecipients`; Esc denies, Enter approves), `<div dsToolCall>` and `<div dsToolCallGroup>` (opens to the arguments and result with Copy; a failed call opens with Retry), and `<article dsPermissionRequest>` (with `dsPermissionScope` and `dsPermissionFiles`; a duration toggle group; Esc denies, Enter allows). Toggle Group gets `allowEmpty` (set `false` for a single choice that always has a value) and Checkbox `fieldClass` (classes on its field).
- fcf2b2e: The patterns Decision Card and Approval Gates for Angular, with the React components' markup and behaviour: `<section dsDecisionCard>` (numbered options and tiles, a number key answers, your own words in the last row, a pager, Later and the folded line) and `<section dsApprovalGates>` with `<div dsApprovalGate>` (A approves, R rejects, Change it edits the arguments first; Esc cancels, Enter approves with changes), `dsApprovalGatesStopped`, `dsApprovalGatesDone`, `dsApprovalGatesDecided` and `<li dsApprovalGatesDecidedItem>`. Input passes `aria-keyshortcuts` to its native input.
- 9fe8cb7: The patterns Decision Inbox, Review Center and Autonomy Dial for Angular, with the React components' markup and behaviour: `<section dsDecisionInbox>` with `<li dsDecisionInboxItem>` and `<li dsDecisionInboxAnswered>` (Undo takes the focus, the row folds away after `dismissAfter`), `<section dsReviewCenter>` with `<li dsReviewCenterQueueItem>`, `<article dsReviewCenterItem>` and `<section dsReviewCenterDone>` (single-key actions, Reject asks why with 1–4, Z undoes), and `<section dsAutonomyDial>` (a three-stop dial; locked actions always ask, with a Tooltip on the lock; `runsOnItsOwn`). With them, all eight stage 1 patterns are in ds-angular. Fix: a closed Tooltip (and other placed popups) now carries its `side` class rather than `top`.
- 8b718d5: The patterns Prompt Library and Memory Panel for Angular, with the React components' markup and behaviour: `<section dsPromptLibrary>` (a searchable list of templates, fields for the gaps, the prompt assembling with its token count, Copy and Use prompt with ⌘↵) and `<section dsMemoryPanel>` (Use memory, categories, every memory with Edit in place, Pause and Forget with Undo, New memory; the list scrolls past `listMaxHeight`).
- 8156965: Select for Angular, with the React Select's markup and behaviour: `<ds-select>` with `options` as data (options, groups, separators, captions; an option's `caption`, `description`, `badge`, `disabled`, and `icon` / `media` as templates that get the option as context), `label`, `caption`, `error`, `placeholder`, `variant`, `size`, `indicator` (check, Checkbox or Radio), `multiple`, `tags` with `tagsOverflow`, `disabled`, `required`, `name` (hidden inputs) and `[(open)]`; `dsLeadingIcon` / `dsTrailingIcon` mark the field's icons. Keyboard (arrows, Home/End, PageUp/PageDown, Enter/Space, Escape, Tab, type-ahead) uses ds-core's list navigation and type-ahead, as React does. The value (`[(value)]`: a string or `null`, a list with `multiple`) works with Signal Forms, Reactive Forms and `ngModel`.
- e199055: Stepper for Angular, with the React component's markup: `<ol dsStepper>` (`orientation`, `variant` indicator or bar, and `steps` with `current`) or `<li dsStepperItem>` children (`state`, `label`, `caption`, `number`, `showLine`, `statusLabel`), numbered by their place. The current step is `aria-current="step"`; done and failed steps say so to screen readers.
- f6f7ecb: The patterns Thinking Loader and Thinking State for Angular, with the React components' markup and behaviour: `<div dsThinkingLoader>` (what it is doing as its content, read out as it changes; `status` thinking, slow with `elapsed` and Stop, done or stopped) and `<div dsThinkingState>` with `<li dsThinkingStep>` steps (`dsThinkingStepIcon`, a spinner while running), `<ul dsThinkingSources>` of `<a dsThinkingSource>` chips with `[more]`, and `<p dsThinkingNote>`; done, it folds to one line that opens back (`[(open)]`).
- c9f17a6: The patterns Writing Assistant and Email Draft for Angular, with the React components' markup and behaviour: `<section dsWritingAssistant>` (the selection, suggestions, the reply streaming in with Stop, then Replace with Enter, Insert below and Copy; a composer marked `dsWritingAssistantComposer`) and `<section dsEmailDraft>` (the recipient Select, the attachment, the text to edit in place, the tone, rewriting, Send with ⌘↵ or Discard, then Undo for a few seconds or Restore). Select takes `aria-labelledby`.
- 6dc4bd3: Badge has a Tint style, Sort UI 2.0's Badge Type=Tint: `variant="tint"` draws the palette tint with its text colour in every colour, plus `amber` and `teal` (Tint only); neutral is 2.0's Secondary. Sizes keep their heights (sm 20 px, lg 24 px) with 2.0's spacing to the text. The patterns drawn on Sort UI 2.0 use it for risk, status and count labels.

### Patch Changes

- 9fe8cb7: Input: the native input now always follows `value`, also when a value is typed and set back before a render. Decision Card clears its last row after Send even when the text was typed and sent at once (it stayed in the field).
- 03feb04: Dialog, Sheet, Drawer and Alert Dialog report Escape at once (on `cancel`), and a late `close` event no longer closes a dialog that was opened again right after Escape.

## 2.57.0

### Minor Changes

- 018a13c: Input and Checkbox for Angular, with the React components' markup: `<ds-input>` (label, caption, error, `variant`, `size`, icons with `dsLeadingIcon` / `dsTrailingIcon`, `prefix` / `suffix` or `[dsPrefix]` / `[dsSuffix]`, `addonBefore` / `addonAfter`, `shortcut`, `blockStart` / `blockEnd` / `blockDivider`, `loading`), `<button dsInputAction>` for the T-slot button, `<ds-checkbox>` (label, caption, error, `control`, `card`, `indeterminate`) and `<fieldset dsCheckboxGroup>`. Both fields work with Signal Forms (`[formField]`: they implement `FormValueControl` / `FormCheckboxControl`), Reactive Forms and `ngModel` (`ControlValueAccessor`), or `[(value)]` / `[(checked)]`. With Signal Forms an invalid value is flagged once the field is touched (left); an `error` message or a hand-set `invalid` shows at once. Adds `@angular/forms` ^22 as a peer dependency.
